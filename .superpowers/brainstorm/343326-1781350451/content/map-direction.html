Proposed Redesign Direction

Which approach feels right for MeetBook?

A

Map-First Experience

Home screen IS a map. Book pins everywhere. Tap a cluster to expand. List view is a secondary tab. Feels like Airbnb/Google Maps.

Pros: Spatial discovery, visual browsing, "what's near me" at a glance
Cons: More complex to build, requires good clustering, can feel cluttered
B

Hybrid: Toggle Between Map & List

Home has a map/list toggle button. Default is list (current behavior), but user can flip to map view with one tap. Best of both worlds.

Pros: User choice, easy migration, low risk
Cons: Two code paths to maintain, toggle can be hidden/missed
C

Card-with-Map Preview

Each BookCard shows a small embedded map preview of its location. Tap to expand full map. List stays primary, but spatial context is always visible.

Pros: Spatial context without leaving list, lightweight
Cons: Many small maps = performance concern, not true map browsing
